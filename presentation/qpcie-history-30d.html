踩過的坑

PITFALLS
🔴

pg054 byte order 高

7-Series PCIe IP（pg054）的 byte order 與自訂介面不一致，造成 128-bit TLP 資料錯位；08-21 統一修正。

🔴

4-DW MWr（64-bit 位址）高

64-bit 主機（如 Jetson）用 iowrite32 產生 4-DW MWr TLP：beat0 是 64-bit 位址、beat1 才是 payload。需在 CQ 側 buffering beat0、把 payload 打包進 cq_tdata[127:96]。

🟡

CplD Tag / Requester ID 中

Completion 回覆的 tag 需依 desc-fetch / H2C/C2H FIFO 正確路由，128-bit TLP 對齊隨 SG descriptor 長度調整。

🟡

128-bit TLP 資料對齊

128-bit 資料路徑的 DW 對齊與 TLP 長度處理需配合 SG descriptor；PCIe bridge 跨越修正。

🟢

ARM64 cache ordering / SMMU

後續（USERPTR/DMABUF）需處理 cache coherency；retained-head SMMU fault 待 Phase2 獨立驗證。
