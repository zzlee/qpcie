症狀

📑

agent 的辦案手法

CASE FILE ② · BANDWIDTH

辦案實錄：沒派上用場的 ILA

📉

症狀：C2H 僅 801 MiB/s

離 Gen2 x4 目標差一半——損失吃在 idle、request 不足、CDC、TLP gap，還是 backpressure？

🚫

決策：ILA 不是第一個工具

ILA 吃 BRAM、window 短，跑不完 4K60 / 600 幀統計。先 qpcie_perfmon + BAR + sysfs 做量化歸因。

📋

備案：探針清單先開好

僅當 counter 指向 tready stall 才上 ILA：s_axis_rq_tvalid/ready、fifo_level、tx_state、trigger 條件就緒。

🏆

結局：ILA 從未實例化

4K60 餘裕 0.22% → 12.6%，靠 perfmon 指引的 RTL 修正。最好的除錯工具，是沒被用上的那個。

PITFALLS

踩過的坑

🔴

pg054 byte order 高

7-Series PCIe IP byte order 與自訂介面不一致，128-bit TLP 資料錯位，08-21 修正。

🔴

4-DW MWr（64-bit 位址）高

iowrite32 產生 4-DW MWr：beat0 是 64-bit 位址、beat1 才是 payload，需在 CQ 側 buffering 後打包進 cq_tdata[127:96]。

🟡

CplD Tag / Requester ID 中

Completion 回覆需依 desc-fetch / H2C / C2H FIFO 正確路由。

🟡

128-bit TLP 資料對齊 中

資料路徑對齊 + TLP 長度處理需配合 SG descriptor。

🟢

ARM64 cache ordering / SMMU 低

USERPTR/DMABUF 時處理 cache coherency；retained head SMMU fault 待 Phase2 驗證。
