## 本輪唯一接續動作（無 production 改動）

留存 host stage 要求 unversioned 的 `usr/lib/libOMX.allegro.core.so` /
`...video_encoder.so`，那是 OE 的 `-dev` 符號連結名稱，運行期 rootfs 從未含過
（已啟 PS 的 20261027-r2 舊包同樣只有 versioned 名稱）。映像內 `sc7f0_vcud` 的
`DT_NEEDED` 正好是 `libOMX.allegro.core.so.1` 與 `libOMX.allegro.video_encoder.so.1`。
因此只以既有 `scripts/package_sc7f0_rootfs.py verify` 改成載入器實際要求的檔名重跑，
其他 `--expect-*` 完全不變；未改 recipe / C++ / kernel / layer / production script，
未重跑 PetaLinux。詳見 `release-26111204-r1/ACCEPTANCE-BASIS.md`（含一處過程失誤與還原說明：
`ps-build-20261112T062817Z/rootfs-runtime-content.{json,log}` 曾被 symlink 上的 `cp` 覆蓋，
已 byte-identical 還原，僅 mtime 改變）。
