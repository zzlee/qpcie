## 19. BAR1 是否需要 PS 存取（預分析，待 0805 驗證後定案）
- 現狀：BAR1（audio 0x1000/EDID 0x2000/TPG 0x3000/0x0000 DECERR hole）僅 PCIe host 可達，跑 `pcie_user_clk`；PS 無路徑。
- 贊成理由：單機 triage 可讀 TPG/EDID 狀態；FSBL/U-Boot 診斷；daemon 可查 video pipeline 健康。
- 反對理由：BAR1 slaves 需快時鐘（TPG 4ppc4K60、HDMI 297MHz），不能搬上 100MHz；PS 要碰就得每 slave 加 CDC（axi_clock_converter）+ 第二仲裁，面積/timing 成本高；每條新 crossing 都重帶 wedge 風險（需 DECERR-safe + 位址窗）；address map 與 driver 複雜度上升。
